# M1.3：会话索引与生命周期管理

M1.3 在 M1.2 本地完整快照的基础上，补充会话命名、列表限制、删除预览和按时间清理。它仍然使用 workspace 内的单文件快照，不引入正文历史、fork 或树状会话。

## 命令

```powershell
# 最近会话，默认最多 50 个
go run ./cmd/drift conversation list
go run ./cmd/drift conversation list --limit 10

# 修改用户自定义标题
go run ./cmd/drift conversation rename <id> "FoxCode 分析"

# 预览过期会话，不会删除
go run ./cmd/drift conversation prune --before 2026-09-01T00:00:00Z

# 确认删除阈值之前的会话
go run ./cmd/drift conversation prune --before 2026-09-01T00:00:00Z --yes

# 精确删除一个会话
go run ./cmd/drift conversation delete <id> --yes
```

所有 `conversation` 命令都在 `.env` 加载和 Provider 创建之前执行，不需要 API Key，也不会发起模型请求。

## 规则

- 标题最多 120 个 UTF-8 字节，禁止换行、NUL 和控制字符；标题由用户主动设置，不自动复制首条提示词。
- `list` 按 `updated_at` 倒序，`--limit` 必须是正整数，默认 50。
- `prune` 没有 `--yes` 时只显示候选会话；带 `--yes` 后才删除更新时间早于阈值的精确快照。
- `prune` 不删除 `.drift/sessions/*.jsonl`，也不会影响其他 workspace。
- `show/list` 只显示元数据，不显示用户提示词、模型回答、工具参数或文件内容。
- 完整快照仍可能包含敏感正文，不应提交 Git 或分享。

## 人工验收

1. 创建两个会话后运行 `conversation list --limit 1`，确认只显示一个最近会话。
2. 执行 `conversation rename <id> "测试会话"`，确认列表显示标题。
3. 运行不带 `--yes` 的 `prune`，确认只预览且文件仍存在。
4. 加上 `--yes` 再运行，确认只删除阈值之前的快照，新的快照和 Session 审计仍保留。
5. 在没有 API Key 的环境中执行 `conversation list/show/rename/prune`，确认命令仍可运行。

## 当前不做

本阶段不实现 JSONL 正文历史、fork、树状导航、`/undo`、自动摘要、正文搜索、导出、加密、云同步、跨 workspace 恢复或后台自动清理。

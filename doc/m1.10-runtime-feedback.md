# M1.10：运行过程反馈

## 目标

让真实终端在模型请求和只读工具执行期间显示安全、可读的进度；完成提示统一使用 ASCII 英文 `Done - 1.2s`，降低 Windows 终端编码差异带来的显示问题。

## 交互约定

```text
  > read_file README.md
  + read_file · 8.2 KB
● Drift 是……
Done - 1.2s
```

- `>` 表示即将执行只读工具；只显示工具名和安全的相对路径。
- `+` 表示工具已返回；只显示工具名和结果字节数。
- 不显示模型思维链、原始 arguments、文件内容、密钥或绝对路径。
- 最终完成标记固定为英文 `Done - <seconds>s`；回答正文仍保持模型原文。
- 真实 TTY 使用颜色和弱化样式；非 TTY 不增加进度行，继续保持纯文本协议。

## 调用流程

Agent 已有 `tool_call` / `tool_result` / `text_delta` 事件。chat 只在 TTY 消费前两类事件做进度渲染，最终文本仍由 `text_delta` 增量输出；审计和 trace 消费路径不变。

## 验收

- TTY 直接回答显示 `●`、正文和 `Done - <seconds>s`。
- TTY 读取文件时显示工具名、相对路径和结果字节数，不显示原始 JSON 参数或文件内容。
- 复杂探索多个工具按调用顺序显示进度，最终回答不重复工具正文。
- 非 TTY 重定向输出不含 ANSI，且完成标记为 `Done`。
- 取消本轮、`/status`、会话保存、trace 和审计 JSONL 不回归。
- `go test ./... -count=1`、`go vet ./...`、`go build ./cmd/drift`、`git diff --check` 全部通过。

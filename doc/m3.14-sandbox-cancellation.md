# M3.14：沙箱进程树取消与超时

## 目标

验证 Linux `bwrap` 与现有命令取消/超时机制的联动，确保取消父进程不会留下可继续执行的 shell 子进程。

## 验收命令

```sh
go test ./internal/tool -run 'TestRequiredBwrap(WritesOnlyWorkspace|CancellationStopsChildProcess|TimeoutStopsChildProcess)$' -count=1
```

测试覆盖：

- workspace 内写入仍可用；
- workspace 外写入失败；
- `.drift`、`.git` 不被污染；
- Ctrl+C 对应 `status=cancelled`；
- 超时对应 `status=timeout`；
- 子进程延迟写入的 marker 文件不会出现。

2026-10-02 已在用户提供的 Linux 环境通过上述测试。验收后已删除远端测试二进制、临时目录并卸载临时安装的 `bubblewrap`。

# M2.2：Workspace 存储布局重命名

## 目标

让目录名称直接表达内容职责：

```text
.drift/
├── sessions/   # 完整会话快照，可用于 --resume
├── audits/     # 脱敏运行审计，只用于排障和审计查看
└── skills/     # Workspace Skills
```

## 当前行为

- `session` 管理 `.drift/sessions/conv-<id>.json`，提供列表、查看、重命名、删除和过期清理。
- `audit` 查看 `.drift/audits/run-<timestamp>.jsonl`，只提供列表和详情查看。
- `session` 与 `audit` 职责严格分离：前者面向可恢复会话，后者面向脱敏运行审计；不保留旧的命令语义兼容。
- 聊天输入区不增加 `/audit`；审计属于进程外排障命令，避免与自然语言输入混淆。
- `.drift/` 整体被 Git 忽略；不新增 `.drift/tmp/`，因为当前没有独立临时结果存储需求。
- 旧 `.drift/conversations/*.json` 和旧 `.drift/sessions/*.jsonl` 均可兼容读取。

## 保守迁移

运行时会在 workspace 选定后准备目录：

- 旧 `conversations/*.json` 迁入新 `sessions/`；
- 旧 `sessions/run-*.jsonl` 逐文件迁入新 `audits/`；
- 目标同名文件存在时不覆盖；
- 新运行只写新目录；
- 旧目录同时存在时，读取逻辑优先新目录并回退旧目录。

本阶段不改变 JSON 快照或 JSONL 审计格式，也不把完整会话改成 JSONL。

## 验收

```powershell
go test ./internal/layout ./internal/conversation ./internal/session ./internal/app -count=1
go run ./cmd/drift session list
go run ./cmd/drift session show conv-<id>
go run ./cmd/drift audit list
go run ./cmd/drift audit show .drift/audits/run-<timestamp>.jsonl
```

确认新运行产生 `sessions/conv-*.json` 和 `audits/run-*.jsonl`，`session` 只读取完整快照，`audit` 只读取 JSONL 审计；旧目录中的数据仍可读取，且不会覆盖新目录中的同名文件。

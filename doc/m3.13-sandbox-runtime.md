# M3.13：Linux bwrap 运行时验收

## 目标

验证现有 `Bash` 沙箱包装在真实 Linux `bwrap` 环境中的最小安全契约，不在本阶段增加新的沙箱后端。

## 运行方式

Linux 主机执行：

```sh
go test ./internal/tool -run TestRequiredBwrapWritesOnlyWorkspace -count=1
```

测试会在没有可靠 `bwrap` 时跳过，并明确写出原因。Windows 只执行交叉编译和全量回归，不能把跳过当成 Linux runtime 通过。

2026-10-02 已在用户提供的 Linux 环境实际运行该测试，结果为 `PASS`。验收后已删除远端测试二进制、临时目录，并卸载临时安装的 `bubblewrap`。

## 验收内容

- workspace 内普通文件可写入；
- workspace 外部路径不会落盘；
- 已存在的 `.drift`、`.git` 被临时隔离，沙箱内写入不会污染宿主目录；
- `/proc/net/route` 无可用路由，确认 `--unshare-net` 生效；
- 命令结果包含 `sandboxed=true`，`required` 不会静默降级。

## 当前限制

Windows 没有等价的文件/网络沙箱实现；`auto` 可记录未启用，`required` 失败关闭。macOS `sandbox-exec` 仍未提供可靠 profile。远程服务器和 Node `sandbox-runtime` 不在 M3.13 范围内。

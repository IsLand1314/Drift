# M1.8：最小终端输入层

## 交付内容

M1.8 为真实终端的 `drift chat` 增加单行输入组件：空输入显示 `Send a message...`，输入时显示受控光标，输入框页脚显示灰色操作提示和右对齐的当前模型名，活动轮 Ctrl+C 显示安全取消信息并继续会话。命令、Agent、会话快照和只读工具边界沿用 M1.7。

非 TTY 输入（管道、重定向和自动化测试）仍使用标准库按行读取，不写 ANSI 控制字符，保证脚本兼容。

## 人工验收

在 Windows Terminal 中运行：

```powershell
go run ./cmd/drift chat -w .
```

检查以下行为：

1. 空闲时看到上下分隔线、青色 `❯` 和灰色 `Send a message...`。
2. 输入文字时占位符消失，文字后出现光标；按 Enter 后只提交一次。
3. 输入框底部左侧显示 `Enter 发送 · Ctrl+C 取消`，右侧显示当前模型名；窗口变窄时不覆盖输入内容。
4. 输入 `/status`，状态面板仍显示 Session ID、Model、Context、Tokens、Tools、Workspace，颜色和缩进保持一致。
5. 模型流式输出期间按 Ctrl+C，看到 `✖ 当前轮已取消；会话仍可继续`，没有原始 `context canceled`，随后可以继续提问。
6. 空闲输入区按 Ctrl+C，进程退出码为 130。

非 TTY 兼容性检查：

```powershell
"/status`nexit`n" | go run ./cmd/drift chat -w . > .codex-temp\m18-output.txt
Select-String -Path .codex-temp\m18-output.txt -Pattern "`e\["
```

最后一条不应输出任何匹配；测试和重定向路径不包含 ANSI 控制序列。

## 边界

本阶段不提供上下历史、多行输入、鼠标、Alt Screen、输入队列、后台任务或完整 FoxCode TUI。只有真实 TTY 使用输入组件；组件不接触 Provider、Agent、会话或工具。

# M1.7：单轮取消

M1.7 让 `drift chat` 在模型流或只读工具执行期间按 Ctrl+C 只取消当前轮，chat 进程继续运行。

## 使用方式

```powershell
go run ./cmd/drift chat -w .
```

在模型持续输出或工具执行期间按 Ctrl+C：

```text
已取消当前轮；会话仍可继续
────────────────────────
❯
```

然后可以继续输入新的问题。空闲等待输入时按 Ctrl+C，chat 以退出码 130 结束。

## 语义边界

- 每条普通输入拥有独立的 child Context；Provider SSE 和只读工具共享该 Context。
- 取消时 Agent 回滚本轮 user、assistant、tool 临时消息，不写入半轮完整会话快照。
- 取消前已完成的历史消息和 Token 统计保持不变；`/clear` 仍会一起清空消息和 Token 统计。
- JSONL 只记录 `type=error`、`stage=agent_cancelled` 和时间，不记录提示词、回答正文、文件内容或工具参数。
- 取消不增加写文件、删除文件、命令执行、TUI 或后台任务能力。

## 人工验收

1. 启动 `go run ./cmd/drift chat -w .`，输入一个会持续输出的问题。
2. 输出过程中按 Ctrl+C，确认出现“已取消当前轮；会话仍可继续”，没有退出 PowerShell。
3. 再输入一个简单问题，确认模型仍能回答。
4. 输入 `/status`，确认历史 Context 和 Token 统计没有因取消被清空或增加半轮数据。
5. 退出后检查最新 `.drift/conversations/*.json`，确认取消轮没有半截 assistant 内容。
6. 检查最新 `.drift/sessions/*.jsonl`，确认有 `agent_cancelled`，且没有提示词、回答正文或原始工具参数。
7. 在没有活动请求、等待 `❯` 输入时按 Ctrl+C，确认进程返回码为 130。

## 当前不做

本阶段不实现 TUI、光标编辑、多行输入、输入队列、后台任务、暂停/恢复单轮和自动重试。

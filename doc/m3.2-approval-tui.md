# M3.2 审批选择器与运行反馈

M3.2 优化 M3.1 的写入审批和工具反馈，不扩大 Drift 的写入权限。

## 行为

- 真实 TTY 使用方向键、数字键和 Enter 选择 `Yes`、`Yes, and don't ask again for this pattern`、`No`；Esc/Ctrl+C 拒绝当前操作。
- 第二项只在当前 chat 进程内记忆，不写入会话、审计或 `.drift/changes`。
- 非 TTY 保留 `y`/`yes` 兼容输入，重定向输出不包含 ANSI。
- 读写工具以灰色开始行、彩色完成/失败行和耗时组成紧凑反馈；完整 diff 只保存在 `.drift/changes`。
- 预检失败向用户展示安全原因，模型收到脱敏摘要；不应读取 Drift 实现源码解释失败。

## 非目标

M3.2 不做永久权限配置、完整全屏 TUI、自动创建目录、删除文件、命令执行、测试运行、OS 沙箱或 Git 回滚。

## 人工验收

```powershell
go run ./cmd/drift chat -w .
```

1. 请求创建一个已存在父目录下的文件；用 ↑/↓ 选择 `Yes` 并回车，确认文件创建。
2. 再请求同类写入，选择第二项，确认同一 chat 内不再重复询问；换路径后应重新询问。
3. 请求写入后按 Esc 或选择 `No`，确认文件不变。
4. 观察审批面板在选择完成后消失，最终只保留简短结果和耗时；不出现完整 diff 头。
5. 用不存在的父目录触发失败，确认显示明确错误，不泄露绝对路径或正文。
6. 使用重定向/测试输入确认非 TTY 没有 ANSI 控制字符。

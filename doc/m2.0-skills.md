# M2.0：Workspace Skills

## 使用方式

在 workspace 内创建：

```text
.drift/skills/project-overview/SKILL.md
```

查看和选择：

```powershell
go run ./cmd/drift skill list -w .
go run ./cmd/drift skill show -w . project-overview
go run ./cmd/drift -skill project-overview -p "分析当前项目"
go run ./cmd/drift chat -skill project-overview -w .
```

## 安全边界

- 只读取当前 workspace 的 `.drift/skills`；不读取全局目录或 workspace 外路径。
- 单个 `SKILL.md` 最大 64 KiB，必须是 UTF-8。
- 一次运行最多加载一个 Skill，必须显式使用 `-skill`。
- Skill 只能提供只读分析说明，不能新增工具、执行命令、修改文件、访问网络或读取 `.env`。
- `skill list/show` 不需要 API Key，也不会请求模型。
- Skill 正文不写入 JSONL 审计和完整会话快照；审计最多记录 Skill 名称。

## 人工验收

1. 创建一个只包含普通 Markdown 的 `.drift/skills/project-overview/SKILL.md`。
2. 运行 `go run ./cmd/drift skill list -w .`，确认只列出 Skill 名称。
3. 运行 `go run ./cmd/drift skill show -w . project-overview`，确认输出本地内容且无需 API Key。
4. 配置现有 OpenAI Compatible Provider，运行 `go run ./cmd/drift -skill project-overview -p "分析当前项目"`。
5. 加上 `--trace`，确认仍只有 `list_files`、`search_text`、`read_file` 三个只读工具。
6. 检查 `.drift/sessions/*.jsonl` 和 `.drift/conversations/*.json`，确认没有 Skill 正文、API Key 或绝对路径。
7. 删除或改名 Skill，再次运行，确认请求前返回错误且不会访问 Provider。

# M2.1：只读探索预算调整

## 目的

真实项目说明通常需要列目录并读取 README、规格、架构等多个文件。原先每次运行最多 6 次工具调用，容易在证据已经充足前进入预算终答，降低 Workspace Skill 的实用性。

## 调整

- 工具调用上限：6 次 → 12 次。
- 模型请求上限：4 次 → 6 次。
- 成功工具结果累计上限：维持 512 KiB。
- 单文件读取上限：维持 128 KiB。
- 不增加用户配置，也不支持无限循环。

## 终答行为

达到工具或读取预算后，Drift 会撤掉 tools schema，并为终答保留请求槽位。每个终答请求都会重新注入只读与 Skill system context；若模型仍请求工具或返回 DSML，运行时只回传受控提示，绝不执行，并在保留槽位内重试普通文本终答。

## 人工验收

```powershell
go run ./cmd/drift --trace -skill project-overview -p "介绍一下当前项目"
```

预期：stderr 中只出现 `list_files`、`search_text`、`read_file`；调用次数最多为 12；stdout 最终输出项目说明。达到预算时不得执行第 13 次工具调用。

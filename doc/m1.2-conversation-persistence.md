# M1.2：本地对话持久化

M1.2 把 `drift chat` 从“进程内存对话”扩展为“默认保存、显式恢复”的本地对话。完整上下文与 M0.9 的脱敏审计严格分离：前者用于恢复，后者用于诊断。

## 使用方式

```powershell
# 默认创建本地完整会话，启动时会显示会话 ID
go run ./cmd/drift chat -w .

# 恢复当前 workspace 最近一次完整会话
go run ./cmd/drift chat --resume -w .

# 恢复指定会话
go run ./cmd/drift chat --resume conv-<id> -w .

# 临时对话：不写完整快照，但仍写脱敏审计
go run ./cmd/drift chat --no-session -w .

# 查看或删除完整会话元数据
go run ./cmd/drift conversation list
go run ./cmd/drift conversation show conv-<id>
go run ./cmd/drift conversation delete conv-<id> --yes
```

`--resume` 只能恢复当前 workspace；不能和文件型 `-w` 或 `--no-session` 同时使用。`/clear` 在持久会话中会先写入空快照，保存成功后才清理内存；保存失败时会保留当前上下文并提示错误。输入普通文本 `clear` 不会调用模型，只提示“如需清空上下文，请输入 /clear”。

## 保存边界

- 完整快照位置：`.drift/conversations/<id>.json`，目录权限目标为 `0700`，文件为 `0600`，写入使用临时文件替换。
- 快照可能包含用户提示词、模型回答和工具结果，**不是脱敏日志，不应上传或分享**。
- 快照不保存 API Key、Authorization、Provider URL、模型名或 workspace 绝对路径。
- `.drift/sessions/*.jsonl` 仍只保存脱敏事件摘要，永远不是恢复来源。
- `conversation list/show` 只显示 ID、时间、focus、消息数量和上下文字节数，不回显正文。
- 默认 chat 创建快照；`--no-session` 完整快照关闭，但审计照常写入。

## 调用流程

```text
CLI 解析 chat 持久化参数
  -> 解析 workspace
  -> 创建新快照，或加载当前 workspace 的快照
  -> Runner 复制消息快照并继续 Agent Loop
  -> 成功完成一轮后保存 Runner 消息
  -> Session Writer 继续写脱敏 JSONL 审计
```

## 当前不做

本阶段不提供分支/fork、树状历史、自动摘要、正文搜索、导出、加密、云同步或跨 workspace 恢复；这些能力应在有明确需求和数据治理方案后单独设计。

## 验收

```powershell
go test ./... -count=1
go vet ./...
go build -o .codex-temp\drift-m12.exe ./cmd/drift
git diff --check
```

人工验收重点：启动两次 chat，第二次用 `--resume <id>` 后确认模型请求包含第一次的上下文；使用 `/clear` 后恢复确认旧消息消失；`--no-session` 不产生 conversations 文件；`conversation show` 不出现提示词或回答正文；删除只影响指定 ID。

**验收操作如下**：

### 1. 验证默认保存

```
go run ./cmd/drift chat -w .
```

输入：

```
请记住临时标记 M12_TEST_123
exit
```

启动时应看到：

```
会话 ID：conv-...
注意：此会话会保存完整本地上下文...
```

查看会话：

```
go run ./cmd/drift conversation list
go run ./cmd/drift conversation show conv-你的ID
```

`show` 应显示 ID、时间、消息数量、上下文字节数，但不能显示提示词正文。

### 2. 验证恢复

```
go run ./cmd/drift chat --resume conv-你的ID -w .
```

输入：

```
我刚才让你记住的临时标记是什么？
```

模型应能根据上次上下文回答 `M12_TEST_123`。

### 3. 验证 `/clear`

在持久化 chat 中输入：

```
/clear
```

应显示：

```
已清空当前对话上下文
```

然后再次询问：

```
我刚才让你记住的临时标记是什么？
```

不应再记得。退出后再次恢复该 ID，也不应恢复旧消息：

```
go run ./cmd/drift chat --resume conv-你的ID -w .
```

### 4. 验证临时模式

```
go run ./cmd/drift chat --no-session -w .
```

输入：

```
临时测试
exit
```

预期：

- `.drift/sessions/` 仍新增审计文件；
- `.drift/conversations/` 不新增完整会话；
- stderr 提示已关闭完整会话保存。

### 5. 验证删除

```
go run ./cmd/drift conversation delete conv-你的ID --yes
go run ./cmd/drift conversation list
```

只能删除指定 ID，其他会话不受影响。

注意：`.drift/conversations/` 保存的是完整本地上下文，可能包含提示词、回答和文件读取结果，不要提交到 Git 或分享。

# M1.6：真实 Token 用量

M1.6 将 Provider 返回的真实 token usage 接入运行时、会话快照、审计和 `/status`，不再把上下文字节估算当作 token 用量。

## 行为

- OpenAI Compatible 流式请求带 `stream_options.include_usage=true`。
- Provider 在 usage-only SSE chunk 中返回输入、输出和总 token；缺失 usage 时显示 `unavailable`。
- Agent 每次成功模型请求产生一个 `model_usage` 事件；完整会话累计 `input_tokens`、`output_tokens`、已报告请求数和未报告请求数。
- `/clear` 同时清空上下文与累计 usage；`--no-session` 仅在当前进程内统计，不写完整会话。
- `/status` 显示 `Tokens: <in> in / <out> out`；同一会话存在未报告请求时追加 `(partial)`。
- JSONL 审计只记录 `model_usage` 事件和数值字段，不记录提示词、回答或文件内容。

## 兼容性

旧会话快照没有 usage 字段时按零值加载；Provider 不支持 `stream_options` 不做自动重试。Context 仍是独立的字节估算，M1.6 不改变 1 MiB 上下文上限。

## 人工验收

1. 使用能返回 usage 的 OpenAI Compatible Provider 完成一次 chat，`/status` 显示输入/输出 token。
2. 使用不返回 usage 的模拟 Provider，确认显示 `Tokens: unavailable`，对话仍成功。
3. 先完成一次有 usage 请求，再制造一次缺失 usage 请求，确认显示 `(partial)`。
4. 输入 `/clear` 后确认 token 统计归零；退出并 `--resume`，确认统计继续保留。
5. 检查 `.drift/sessions/*.jsonl`，确认只有事件名和数值 usage 字段，没有正文或原始参数。

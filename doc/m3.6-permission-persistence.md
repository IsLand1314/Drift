# M3.6 阶段说明：工作区权限策略持久化

M3.6 已完成工作区级权限策略的最小闭环：读取精确规则、审批成功后保存、跨 chat 复用、查看和清除。

## 已实现

- `.drift/permissions.json`，版本化 JSON，工作区级隔离；
- `write_file`、`edit_file`、`delete_file`、`run_command` 使用工具 + 操作 + 路径/命令 + cwd 精确匹配；
- 只有选择“允许此类操作”且工具执行成功后才写入；
- 写入失败、拒绝、取消和损坏配置均不自动放行；
- `/permissions` 和 `/permissions clear`；
- 策略文件使用 `0600`，同目录临时文件原子替换；
- 现有 workspace、符号链接、隐藏目录、特殊文件和命令边界不被策略绕过。

## 2. 安全审计

| 当前界面操作                                | 实际含义                         |
| ------------------------------------------- | -------------------------------- |
| `Yes`                                       | 只允许本次操作                   |
| `Yes, and don't ask again for this pattern` | 允许匹配的工具、操作和路径规则   |
| `No`                                        | 拒绝本次操作，不写入永久允许规则 |
| `Esc / Ctrl+C`                              | 取消当前审批或当前操作           |

而 `permissions` 权限模式是另一层，当前只有四种：

```
default             写入、编辑、删除和命令需要确认
acceptEdits         自动允许写入和编辑，删除和命令仍需确认
plan                只读计划模式，拒绝所有修改、删除和命令
bypassPermissions   跳过普通审批，但不越过 workspace 和沙箱安全边界
```

权限模式决定策略层是否允许、拒绝或要求审批，不是审批弹窗里的选项：

```
权限模式（四选一）
    ↓
内部策略结果：allow / ask / deny
    ↓（仅 ask 进入人工确认）
具体审批结果：allow_once / allow_persistent / deny / cancelled
```

- `Yes`：只执行当前这一次；
- `Yes, and don't ask again for this pattern`：对精确匹配规则放行；
- `No`：当前操作拒绝；
- `Esc / Ctrl+C`：取消当前审批或当前操作；
- `/permissions`：查看并切换四种权限模式；
- `/permissions clear`：清除持久化规则。

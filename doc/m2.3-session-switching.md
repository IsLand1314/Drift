# M2.3：聊天内会话切换

## 状态

已实现并完成自动化验证；人工验收记录见 `artifacts/verification/m2.3/manual-acceptance.txt`。

## 目标

让用户不退出 `drift chat` 就能浏览、切换和新建完整会话，同时保持当前 M2.2 的存储职责：

```text
.drift/sessions/  # 完整会话快照，resume 的唯一来源
.drift/audits/    # 脱敏运行审计，不参与恢复
```

本阶段仍然只提供 `list_files`、`search_text`、`read_file` 三个只读工具，不增加写文件、删除文件或命令执行能力。

## 用户入口

### `/resume`

不带参数时打开会话选择器：

```text
Resume session (1 of 4)

⌕ Search…

❯ README 读取与项目说明
    5 minutes ago · 34 messages · 107 KB

  FoxCode 项目分析
    yesterday · 7 messages · 78 KB

Type to search · Enter to select · Esc to cancel
```

选择器行为：

- 输入字符按标题、首条用户消息和会话 ID 做本地过滤；
- `↑/↓` 移动当前项；`Enter` 选择；`Esc` 取消；
- 当前项使用青色和 `❯` 标记，未选项使用普通文本；
- 列表只读取当前 workspace 的完整会话元数据；
- 只显示至少包含一条消息的完整会话；空快照不会出现在选择器中，也不会被自动删除；
- 首条用户消息只在本地选择器中作为预览，不写入审计；
- 没有会话时显示明确的空状态和 `/new` 提示。

### `/resume <id>`

直接加载指定会话 ID。ID 必须是当前 workspace 中存在的合法会话 ID；不接受任意文件路径，也不跨 workspace 加载。

### `/new`

保存当前会话后创建一个新的空会话，并把当前输入区、消息展示和 Runner 上下文切换到新会话。旧会话仍保留在 `.drift/sessions/` 中。

### `/rename <标题>`

更新当前持久会话的本地标题。标题写入完整会话快照，不请求 Provider，不写入脱敏审计；之后打开 `/resume` 时优先显示该标题。`--no-session` 模式没有可保存的会话标题。

## 切换流程

```text
用户输入 /resume
  ↓
列出当前 workspace 的完整会话
  ↓
本地搜索 / 上下移动 / Enter 选择
  ↓
校验 ID 并加载目标快照
  ↓
重建 Runner 消息、Session ID、状态统计
  ↓
切换成功后刷新消息区与底部状态栏
```

切换必须采用“先加载、后替换”原则：

1. 在临时状态中读取并校验目标快照；
2. 确认消息结构、workspace、会话 ID 均合法；
3. 目标加载成功后，再一次性替换当前 Runner 和展示状态；
4. 任意失败或用户取消时，当前会话、消息和输入草稿保持不变。

切换只允许发生在当前轮次空闲时。模型流式输出、工具执行或 `/compact` 进行期间，`/resume` 应提示先等待或使用 Ctrl+C 取消当前轮次。

## `/new` 的保存语义

- 持久化模式下，先保存当前完整快照，再创建新会话；
- 当前快照保存失败时不创建新会话，原会话继续使用；
- `--no-session` 模式不创建磁盘快照，但仍可清空进程内 Runner 并开始新的临时上下文；
- `/new` 不删除、不修改旧会话文件；
- 新会话的审计继续写入新的 `.drift/audits/run-*.jsonl`，审计不作为恢复输入。

## 与现有入口的关系

以下入口继续保留：

```powershell
go run ./cmd/drift chat --resume -w .
go run ./cmd/drift chat --resume conv-<id> -w .
go run ./cmd/drift session list
go run ./cmd/drift audit list
```

M2.3 增加 chat 内的 `/resume`、`/new` 和 `/rename`，不增加 `/audit`。`session` CLI 仍然管理完整会话，`audit` CLI 仍然只查看审计。

## 明确不做

- 不改现有 JSON 快照格式；
- 不把会话改为树状 JSONL；
- 不增加 `/tree`、`/fork`、`/clone`；
- 不在选择器中直接删除会话；删除继续使用 `drift session delete <id> --yes`；
- 不读取或展示审计正文；
- 不增加写文件、编辑文件、shell 或 exec；
- 不引入 FoxCode 的 writer lock、FileHistory、Todo 或 MCP 重绑定。

## 实现边界

优先复用现有组件：

- `internal/conversation.Store`：列表、加载、创建和保存完整快照；
- `internal/app/chat.go`：slash 命令解析和 chat 生命周期；
- `internal/app/chat_input.go`：输入框和 Bubble Tea 事件；
- `internal/app/chat_persistence.go`：持久化模式与 `--no-session` 分支；
- 当前状态面板：继续显示 Session ID、Model、Context、Tokens、Tools 和 Workspace。

选择器只需要一个轻量状态：候选会话、过滤文本、当前索引和滚动偏移，不新增持久化格式或索引文件。

## 人工验收脚本

```text
1. 启动：go run ./cmd/drift chat -w .
2. 输入：/resume
3. 输入项目名或首条消息的一部分，确认列表过滤。
4. 使用 ↑/↓ 和 Enter 选择另一个会话。
5. 输入：/status，确认 Session ID 和 Context 已切换。
6. 输入：/resume <id>，确认可以直接切换。
7. 再次输入：/resume，按 Esc，确认当前会话不变。
8. 输入：/new，确认获得新的 Session ID。
9. 输入：/rename 基本认识，再输入 /resume，确认当前会话显示新标题。
10. 退出后执行：drift session list 和 drift audit list，确认两类文件仍然分离。
```

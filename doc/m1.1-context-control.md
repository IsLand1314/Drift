# M1.1：交互上下文管理

M1.1 为 M1.0 的 `drift chat` 增加进程内上下文管理，解决长时间交互导致消息不断累积的问题。

## 当前能力

- Runner 按 UTF-8 字节估算 system 指令、消息、tool call、tool result、reasoning content 和工具 schema；初始上限为 1 MiB。
- 每次 Provider 请求前检查上下文预算。超过上限时不发请求，写入 `stage=agent_context_limit` 的安全错误事件。
- `chat` 输入 `/clear` 会清空当前进程的 user/assistant/tool 消息，输出“已清空当前对话上下文”，但保留 workspace、focus、Provider 和工具注册表。
- 上下文超限只结束当前输入轮次，chat 继续等待；终端提示用户输入 `/clear` 后继续。
- 单次 `-p`、M1.0 多轮工具循环、空响应错误、Session 脱敏和 Provider 阶段错误保持不变。

## 使用方式

```powershell
go run ./cmd/drift chat -w .
> 读取 README.md
> /clear
> 这个项目的作用是什么？
> exit
```

`/clear` 不会请求模型、不创建新的 Session 文件，也不会删除已有审计记录。它只影响下一次请求携带的内存消息；终端输出确认文案，方便人工判断清理已完成。

## 调用流程

```text
输入普通问题
  -> Runner 追加 user 消息
  -> 估算 system + messages + tools
  -> 未超过 1 MiB：执行现有只读 Agent Loop
  -> 超过 1 MiB：写 agent_context_limit，保持 chat 运行

输入 /clear
  -> Runner.ResetContext()
  -> stdout 输出“已清空当前对话上下文”
  -> 保留 workspace/focus/provider/registry
  -> 等待下一条问题
```

上下文预算是保守的字节估算，不等同于模型 token 数。它不读取 Session JSONL，也不把审计内容重新发送给模型。

## 明确边界

- 不自动截断旧消息；
- 不调用模型生成摘要；
- 不从 Session 恢复上下文；
- 不新增写文件、编辑文件、Shell、exec 或 Provider；
- 不控制 Windows Terminal/PowerShell 的上箭头历史。

## 人工验收

```powershell
go run ./cmd/drift chat -w .
> 请记住一个临时暗号：DRIFT_TEST_123
好的，我记住了：临时暗号是 **DRIFT_TEST_123**。

几点说明，避免误会：

- 这只在**当前对话**中有效。我没有跨会话的持久记忆，如果之后开启新对话，我不会记得这个暗号。
- 我不会把它写入任何文件或发送到外部——我只有只读工作区工具，本题也未要求我做任何操作。
- 如果这个暗号本身是敏感信息（比如口令、密钥），建议不要长期复用；放在对话里可能被记录。

需要我现在用它做什么吗？
> 我刚才让你记住的暗号是什么？
你刚才让我记住的临时暗号是：**DRIFT_TEST_123**。
> /clear
> 我刚才让你记住的暗号是什么？
我没有找到任何暗号，也无法回答这个问题。

原因如下：

1. **本轮对话中你没有给我任何暗号。** 在你能看到的这段对话里，你的第一条消息就是“我刚才让你记住的暗号是什么？”，之前并不存在让我记住某段内容的历史。

2. **我也没有跨会话的持久记忆。** 每次对话之间我不会保留“上次让你记住的东西”。如果你真的在某个更早的会话里交代过暗号，那个信息不会自动带到这里来。

3. **我在当前工作区里搜过了，也没有线索。** 我检索了 “暗号”“记住”“remember” 等关键词，只在 `doc/Process/代码理解.md` 里看到一句“先记住的总调用链”，那只是文档里的小标题，不是暗号；其余没有相关记录。

所以结论是：我这边没有可复述的暗号。如果它确实重要，麻烦你直接把它再发我一次；如果它本来应该被存进某个文件或会话记录里，也可以告诉我预期位置，我可以帮你确认是否遗漏了。
```

检查第二个问题的模型请求不包含第一轮消息。使用足够长的输入触发限制时，终端应提示：

```text
错误：对话上下文已达到上限，请输入 /clear 后继续
```

输入 `/clear` 后 chat 应继续工作；`session show` 中应能看到 `agent_context_limit`，但不能看到完整提示词、回答正文、文件内容、密钥或绝对路径。

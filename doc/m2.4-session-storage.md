# M2.4：按日期分片的会话与审计存储

状态：已实现，待人工验收。

## 目标

M2.4 只调整本地文件组织，不改变会话 JSON 快照和审计 JSONL 的内容格式：

```text
.drift/
├── sessions/
│   └── YYYY/MM/DD/session-<timestamp>-<id>.json
├── audits/
│   └── YYYY/MM/DD/run-<timestamp>-<audit-id>.jsonl
└── skills/
```

日期使用 UTC。会话按 `CreatedAt` 归档，后续 `/rename`、消息保存不会改变目录；审计按本次运行开始时间归档。

## 命令职责

`session` 只管理完整可恢复会话：

```text
session list/show/rename/delete/prune
```

`audit` 只读取脱敏运行记录：

```text
audit list/show
```

审计不支持重命名、删除或清理命令。旧的 `.drift/sessions/*.json`、`.drift/sessions/*.jsonl` 和 `.drift/conversations/*.json` 不再兼容读取，也不会自动迁移。

## 实现边界

- `conversation.Store` 递归扫描日期目录；保存使用临时文件和原子替换；
- 文件名采用“前缀-时间-ID”结构，时间使用 Windows 安全的 `YYYY-MM-DDTHH-mm-ssZ`；
- 审计查看器递归扫描 `.drift/audits/`，跳过符号链接；
- 不增加索引文件；当前规模下递归扫描足够简单可靠；
- 清理旧数据由用户显式执行，不在启动时隐式删除；
- `.drift/` 继续整体被 Git 忽略。

## 人工验收

```text
1. go run ./cmd/drift chat -w .
2. 输入一条问题并退出。
3. 检查 .drift/sessions/YYYY/MM/DD/ 与 .drift/audits/YYYY/MM/DD/ 均生成对应文件。
4. 运行 drift session list，确认能列出日期目录中的会话。
5. 运行 drift audit list，确认能列出日期目录中的审计。
6. 运行 drift audit rename/delete/prune，确认命令不存在。
7. 将旧平铺文件放入旧路径后运行 list/show，确认不会被读取。
```

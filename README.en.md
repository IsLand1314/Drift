# Drift

#### Description
面向本地代码仓库的 Coding Agent Runtime，实现流式模型交互与工具调度，集成 MCP 工具按需加载、上下文预算与压缩恢复、跨会话记忆、分层权限控制及多 Agent 任务协作，并提供 TUI 与远程 Web 交互入口 ，协助理解代码推进到修改和验证。

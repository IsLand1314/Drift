# M5.19：Provider 能力声明与 Native 策略

## 已完成

- `llm.Capabilities` 区分 `NativeToolCalls` 与 `NativeToolReferences`。
- OpenAI Compatible、Anthropic Messages 声明支持原生 Tool Call。
- Codex 登录态暂不声明工具能力，保持 text-only。
- `native` 策略根据 Provider 能力决定：只有 `NativeToolReferences=true` 才真正启用，否则降级为 `dispatch`。
- 添加了 native 支持和安全降级的回归测试。

## 边界

原生 Tool Call 与原生 deferred tool reference 不是同一能力。当前 OpenAI/Anthropic 已经可以执行普通原生工具调用，但尚未提供 Drift 可直接使用的延迟工具引用协议，因此不能把 `NativeToolCalls=true` 误判为 `NativeToolReferences=true`。

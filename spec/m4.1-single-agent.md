# M4.1：单子 Agent 闭环

## 目标

主 Agent 能创建一个子 Agent，让它在指定 Worktree 中执行任务，并可靠回传成功、失败、取消或超时结果。

## 范围

- 一个主 Agent 同时最多运行一个子 Agent；
- 子 Agent 拥有独立 Runner、消息上下文和工具注册表；
- 子 Agent 使用任务绑定的 Worktree；
- 支持显式取消、上下文超时和结束后的资源回收；
- 每次生命周期写入可区分的审计事件；
- 主 Agent 通过 `TaskRun`、`TaskStatus`、`TaskCancel` 控制生命周期；终态结果和错误可通过 `TaskStatus` 读取；
- 不实现并行、多 Agent DAG、Agent 间消息和自动合并策略。

## 状态

```text
pending → running → completed
                  ↘ failed
                  ↘ cancelled
                  ↘ timeout
```

主会话必须保持可继续输入；子 Agent 的失败或取消不能让主会话进程崩溃。

`TaskRun` 只启动异步子 Agent 并立即返回 `in_progress`；主 Agent 随后使用
`TaskStatus` 轮询，或使用 `TaskCancel` 请求取消。成功、失败、取消和超时会分别
写入任务状态、子 Agent 生命周期审计事件，并保留结果摘要。退出主会话时，宿主会
取消活动子 Agent、等待其释放运行槽位，但不会删除或重置 Worktree。

## 验收

确定性验收至少覆盖：成功、工具失败、显式取消、超时、Worktree 不存在、主会话继续、审计字段和资源回收。独立 LLM 验收必须使用新上下文、只读权限，输出 `PASS/FAIL/BLOCKED` 和问题清单。

# M5.12-B：短期记忆

## 目标

为当前 Session 提供小型、结构化、可恢复的短期记忆；它不是完整 transcript，也不允许模型把未经确认的任意内容自动写入。

## 已交付

- `internal/memory.Store` 支持 `fact`、`decision`、`constraint`、`open_task` 四类条目；
- 条目有大小、数量、敏感字段和绝对路径限制；
- 支持 Remember、Replace、Delete、Clear 和 PromptText；
- Runner 在首个 Provider 请求的系统上下文中注入短期记忆；
- Conversation Snapshot 保存并恢复短期记忆；
- 新会话和 `/clear` 会清空短期记忆；
- 记忆只接受显式 API 写入，自动提取留到后续经验阶段。

## 非目标

- 不跨 Session 自动共享；
- 不建立向量索引；
- 不让短期记忆覆盖用户当前指令、权限或沙箱策略；
- 不保存 API Key、绝对路径或完整命令输出。

## 验收

- Store 单测覆盖新增、去重、替换、删除和敏感信息拒绝；
- Runner 测试确认记忆只出现在系统上下文；
- Conversation Store 测试确认 Session 恢复保留记忆；
- 全量测试、race、vet、build 和 diff check 通过。

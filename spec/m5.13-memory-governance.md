# M5.13：Memory 质量与治理

## 目标

让长期记忆可检索、可审查、可过期，而不是把未确认经验直接塞进模型上下文。

## 规则

- `fact`、`decision` 默认可检索；`experience` 默认只返回 `verified`；
- `MemorySearch` 支持 `kind`、`status`、`limit` 过滤；
- 过期条目通过 `PruneBefore` 清理，并同步 `index.json`；
- 候选经验仍必须经过用户确认，不自动升级；
- 不引入向量数据库，继续使用 workspace 内 JSONL。

## 验收

- 未验证经验默认不可被 `MemorySearch` 返回；
- 显式 `status=candidate` 可以审查候选；
- 过期清理不会影响其他类型记忆；
- `go test ./...`、`go test -race ./...`、`go vet ./...`、build、diff check 全部通过；
- 真实 LLM 链路只加载 `MemorySearch` 时，结果不包含候选经验。

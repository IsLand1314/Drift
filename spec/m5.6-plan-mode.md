# M5.6：Plan Mode 流程

Plan Mode 是权限模式 `plan` 的显式 Agent 流程，不是新的沙箱或审批模式。

## 行为

- `EnterPlanMode` 不修改 workspace，进入只读计划状态；
- 计划状态下只有读取、搜索、任务和澄清工具可执行；
- `WriteFile`、`EditFile`、`DeleteFile`、`Bash` 和 MCP 修改调用继续被拒绝；
- `ExitPlanMode` 只能从计划状态退出，并进入现有审批链；
- 退出获批后恢复 `default` 权限模式；拒绝或取消时仍留在计划状态；
- 进入、退出、拒绝和取消沿用现有 Agent 事件与审计链路。

## 边界

Plan Mode 不创建新的文件权限规则，不绕过 OS 沙箱，不改变 MCP 连接策略，也不实现自动执行计划。计划工具只负责状态转换，具体修改仍需后续普通工具调用和现有审批。

## 验收

```text
go test ./internal/tool -run TestPlanModeToolsAreAvailableAndSideEffectFree -count=1
go test ./internal/app -run TestPlanModeTransitions -count=1
go test ./internal/agent -run TestPlanModeToolInvokesTransitionHookAfterApproval -count=1
```

全量门禁仍为 `go test ./... -count=1`、`go vet ./...` 和 `go build ./cmd/drift`。

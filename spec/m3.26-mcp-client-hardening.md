# M3.26：MCP Client 生命周期收口

本阶段只强化 Drift 作为 MCP Host/Client 的本地 stdio 连接，不实现 MCP Server、HTTP/SSE 或远程 transport。

## 已交付

- MCP Server 子进程只继承最小运行时环境（如 `PATH`、临时目录和 Windows 系统目录），并由 `env_refs` 提供显式覆盖；
- 初始化、发现和调用失败时关闭客户端连接；
- 调用上下文取消或 stdio 断连时终止并等待 MCP Server 进程；
- 已关闭客户端拒绝后续工具调用；
- 保持现有 `ToolSearch → 权限审批 → tools/call` 链路不变。

## 未纳入本阶段

- MCP Server 对外监听；
- HTTP、SSE、Streamable HTTP；
- MCP resources/prompts/sampling；
- eager/native/dispatch 自适应策略；
- MCP Server 的 OS 沙箱接入（下一轮单独收口，避免与 stdio 生命周期改动混在一起）。

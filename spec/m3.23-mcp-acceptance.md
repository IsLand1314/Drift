# M3.23：MCP 集成验收与失败路径收口

本阶段只收口 M3.22 的本地 stdio MCP：连接取消必须停止发现流程；显式连接、ToolSearch 延迟加载、权限和 JSONL 审计必须可回归验证。远程 transport、OAuth、自动连接和持久化 MCP 授权仍不在范围内。

## 交付内容

- `AttachMCP` 使用调用方上下文执行 `tools/list`，取消不会退化为不可取消的后台请求；
- 真实 stdio helper 集成测试覆盖 `/mcp connect` 所需的配置、连接保持、ToolSearch 加载和连接审计；
- 连接失败、协议失败和关闭路径继续沿用现有错误分类，不泄露 MCP 结果正文或环境变量值。

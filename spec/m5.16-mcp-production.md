# M5.16：MCP 生产化收口

## 范围

- `.drift/mcp.json` 支持 `retry_count`（0–3）和 `timeout_ms`（100–120000）；缺省为一次连接、10 秒握手超时；
- 单次显式 `connect` 在失败时按 100ms、200ms、300ms 递增间隔有限重试；不启动后台重连；
- 连接失败统一带 transport、阶段和尝试次数，不记录密钥、请求正文或响应正文；
- `/mcp status` 展示 server、连接状态、transport、重试配置和 capability 缓存状态；
- 保持既有 sandbox、权限、Resource/Prompt 不可信内容和审计边界。

## 非目标

- 不实现 MCP Server；
- 不引入远程执行沙箱；
- 不自动修改配置或凭据；
- 不对已经连接的 server 做后台重连。

## 验收

| ID | 验证 | 通过标准 |
| --- | --- | --- |
| AC-M516-001 | 配置单测 | 合法 retry/timeout 被接受，越界配置明确拒绝 |
| AC-M516-002 | stdio 外部 server | 第一次初始化失败、第二次成功时 connect 成功且状态为 connected |
| AC-M516-003 | 状态查询 | `/mcp status` 返回 transport、状态、retry 和 capability 缓存 |
| AC-M516-004 | 失败诊断 | 最终错误含阶段和尝试次数，不含凭据和正文 |
| AC-M516-005 | 回归 | 全量 test、race、vet、build 和 diff check 通过 |

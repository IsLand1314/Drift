# M5.9：计划任务执行与子 Agent 编排

M5.9 将 M5.8 的结构化计划接入已有 TaskRunner，不新增并行执行器。

## 行为

- `PlanUpdate` 自动把计划任务同步为当前会话的 Task；
- 每个任务必须使用现有受管 Worktree 才能执行子 Agent；
- `PlanExecute` 仅在退出 Plan Mode 后可调用；
- 任务按计划顺序和依赖逐个执行，复用 `TaskRun` 的超时、取消、结果和合并状态；
- 依赖未完成、子 Agent 失败或上下文取消时，后续任务不会执行；
- 执行结果仍通过 `TaskStatus`、会话快照和审计查看。

## 安全边界

计划不会绕过权限、审批、沙箱或 Worktree 隔离。没有可用 TaskRunner 或 Worktree 时，`PlanExecute` 明确失败，不回退到主工作区执行。

## 验收

```text
EnterPlanMode → PlanUpdate → ExitPlanMode → PlanExecute → TaskStatus
```

验证依赖完成后按顺序运行；失败任务阻断后续任务；旧会话仍可加载为空计划。

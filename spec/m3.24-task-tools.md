# M3.24：会话内任务管理最小闭环

本阶段新增 `TaskCreate`、`TaskList`、`TaskGet`、`TaskUpdate` 四个控制工具。任务表只属于当前 chat 进程，必须先通过 `ToolSearch` 加载；任务工具不修改 workspace、不需要审批，结果沿用现有 Agent tool result 和 JSONL 审计链路。

## 边界

- 支持 `pending`、`in_progress`、`completed`、`cancelled`；
- `TaskCreate` 生成当前会话内递增的 `task-N` ID；
- 未知任务、非法状态、空标题和超长字段拒绝；
- 暂不实现跨进程恢复、任务依赖、并行 Agent、worktree 或远程同步。

# M5.26：Anthropic Provider 与外部 MCP 真实链路

## 范围

- 使用 `.drift/config.toml` 的 `protocol = "anthropic"` 和 DeepSeek Anthropic-compatible endpoint 验证文本请求。
- 使用 `tool-loading = native` 验证原生工具调用仍能驱动 Drift 的 `ReadFile`。
- 使用 `@modelcontextprotocol/server-filesystem` 作为本地 stdio 外部 MCP，验证连接、发现、ToolSearch、审批、调用和审计。
- 浏览器 MCP 只做 CLI 可用性探针，不加入项目配置，不访问外部站点。

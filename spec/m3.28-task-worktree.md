# M3.28：任务 Worktree 绑定

## 目标

让任务状态能表达“在哪个隔离 worktree 中执行”，为后续 Agent 调度提供稳定元数据：

```json
{"subject":"implement feature","worktree":".worktrees/agent-1"}
```

`TaskCreate` 和 `TaskUpdate` 支持可选 `worktree`；`TaskGet`、`TaskList`、会话快照和恢复会保留它。

## 边界

- M3.27 负责实际创建、列出和删除 Git worktree。
- M3.28 只绑定任务元数据，不自动创建或删除目录。
- 任务完成或取消不自动删除 worktree，避免误删未合并代码。
- 不实现 Agent 自动调度、并行执行、合并和冲突解决。

## 安全规则

绑定路径必须是单段受控路径 `.worktrees/<name>`，名称遵循 `[A-Za-z0-9][A-Za-z0-9._-]{0,63}`；绝对路径、`..`、额外目录层级和 workspace 外路径均拒绝。

## 验收

```text
go test ./internal/tool -run TestTaskWorktreeBindingIsPersistedAndPathScoped -count=1
go test ./... -count=1
go vet ./...
go build ./cmd/drift
git diff --check
```

通过条件：绑定可创建、更新、导出和恢复；越界路径拒绝；任务状态变化不删除绑定目录。

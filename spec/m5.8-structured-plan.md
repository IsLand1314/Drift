# M5.8：结构化 Plan 与会话恢复

M5.8 在现有 Plan Mode 和任务状态机之上增加结构化计划，不新增第二套执行器。

## 范围

- `PlanUpdate` 仅在 `planning` 阶段可用；
- 计划包含目标、任务、风险和验收项；
- 计划 ID、阶段和内容随会话快照保存；
- 恢复或切换会话时同时恢复计划和已有 Task 状态；
- 进入 Plan Mode 自动生成计划 ID，退出后仍保留计划用于执行汇报；
- 计划更新仍遵守现有只读规划边界，不执行文件、命令或 Git 修改。

## 不在本阶段

- 不自动把计划任务创建成子 Agent；
- 不自动执行计划或自动修改任务状态；
- 不引入新的任务 DAG；计划任务可通过现有 Task 工具继续细化；
- 不改变审批、沙箱和 MCP 策略。

## 验收

```text
ToolSearch → EnterPlanMode → PlanUpdate → ExitPlanMode
```

应能保存并恢复 `plan_id`、`plan_phase`、目标、任务、风险和验收项；旧快照缺少计划字段时按空计划兼容加载。

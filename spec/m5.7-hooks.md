# M5.7：生命周期 Hooks

第一版只支持 `.drift/settings.toml` 中的本地命令 Hook。Hook 不拥有独立权限，命令仍通过 Drift 的审批、workspace 边界、沙箱、超时和审计链路执行。

支持事件：`session_start`、`session_end`、`turn_start`、`turn_end`、`pre_tool_use`、`post_tool_use`、`plan_state_changed`。

```toml
[[hooks]]
id = "after-edit"
event = "post_tool_use"
tool = "EditFile"
match = "*.go"
command = "go test ./..."
timeout_ms = 30000
on_error = "report"
```

`pre_tool_use` Hook 返回拒绝时，工具不会执行；`post_tool_use` 默认报告但不回滚已完成工具；`on_error = "ignore"` 忽略失败，`on_error = "block"` 阻断当前流程。命令在 workspace 根目录执行，`match` 使用 Go 文件名模式；第一版不支持 HTTP、Agent、网络 Hook 或动态脚本模板。

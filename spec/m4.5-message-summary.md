# M4.5：Agent 消息与结果汇总

## 目标

让主 Agent 和子 Agent 传递可追踪的进度、问题和结果，并能按任务生成不重复的汇总。

## 规则

1. 每条消息必须包含 `id`、`from`、`to`、`task_id`、`kind`、`text` 和 UTC `time`。
2. `kind` 只允许 `progress`、`issue`、`result`；消息总线不授予权限，也不执行工具。
3. 相同消息 ID 幂等丢弃，查询按时间排序，确保结果不重复、不丢失。
4. `AgentMessageSend`、`AgentMessageList`、`AgentSummary` 供主 Agent 按需加载。
5. 子 Agent 启动和结束会自动发送 progress/result 消息；主 Agent 通过 `AgentSummary` 生成汇报。

## 边界

- 当前总线是单进程、单会话内存实现；不提供远程消息服务或跨进程持久化。
- 消息不改变权限模式、审批结果或沙箱边界。

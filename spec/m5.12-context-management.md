# M5.12-A：上下文管理

M5.12-A 在现有 M3.20 上下文压缩基础上补齐自动压缩、有效工具边界和失败原子性。Session 仍是完整记录，Context 仍是当前发送给 Provider 的内存消息投影。

## 已交付

- `Runner.Compact` 在保留消息时不会从孤立的 assistant tool call 或 tool result 开始；
- Runner 在请求前接近 80% 字节预算时自动压缩一次；
- 压缩摘要为空、含 DSML/伪工具格式或 Provider 失败时，原消息数组保持不变；
- 压缩生命周期只记录计数、字节数和状态，不记录摘要正文；
- 现有 Conversation Store 恢复消息、Plan、Task、Provider/workspace 选择后，继续通过同一 Runner Context 计算路径；
- 不引入 Memory、向量数据库、外部知识库或 Skill 生命周期。

## 约束

- UTF-8 字节数是保守预算，不是 token 计数；
- API Key、完整命令输出和未经脱敏的绝对路径不得进入摘要元数据；
- 权限、沙箱、Coordinator 和工具注册行为不改变。

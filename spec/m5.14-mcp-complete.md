# M5.14：MCP Client 完整能力

## 范围

Drift 仍然只作为 MCP Client，不对外提供 MCP Server。

- stdio、HTTP、Streamable HTTP 连接；
- `tools/list` / `tools/call`；
- `resources/list` / `resources/read`；
- `prompts/list` / `prompts/get`；
- Resource 和 Prompt 通过 `mcp__<server>__resource_read`、`mcp__<server>__prompt_get` 按需加载给模型；
- HTTP 状态、SSE 响应、超时、大小限制和关闭处理；
- Header 环境变量引用不把密钥写入日志；
- MCP 工具继续进入现有审批、沙箱和审计链路。

## 验收

- stdio 回归测试通过；
- httptest Server 覆盖初始化、工具、资源和 Prompt；
- 非 2xx、非法 JSON、超限响应和取消请求被拒绝；
- `/mcp resources <name>` 与 `/mcp prompts <name>` 可发现已连接内容；
- ToolSearch 加载 Resource/Prompt 后可完成只读调用；
- 全量 test、race、vet、build、diff check 通过。

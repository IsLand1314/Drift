# M5.3：读取快照与编辑一致性

## 目标

防止模型读取文件后，文件被外部修改，随后 EditFile 使用过期上下文继续编辑。

## 行为

- ReadFile 成功后，在当前进程内记录 workspace、相对路径、文件大小、修改时间和 SHA-256 摘要。
- EditFile 生成预览前检查已有读取快照；文件变化时拒绝编辑。
- 成功的 WriteFile、EditFile、DeleteFile 会使对应缓存失效。
- 缓存不写入会话、审计或磁盘；恢复会话后必须重新读取文件。
- 原有预览到提交之间的状态校验继续保留，覆盖审批等待期间的并发修改。

## 验收

```text
ReadFile → 外部修改 → EditFile：拒绝，原文件保持不变
ReadFile → EditFile → 再次 EditFile：允许，旧快照已失效
```

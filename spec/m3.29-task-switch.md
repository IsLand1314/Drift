# M3.29：任务创建与切换

## 目标

在已有 M3.27/M3.28 基础上提供任务切换：

1. `TaskCreate` 创建带 `.worktrees/<name>` 绑定的任务；
2. `TaskSwitch` 选择任务并验证 worktree 已存在；
3. Agent 在 `TaskSwitch` 成功后，把后续工具调用的 workspace 根切换到该 worktree。

## 边界

- worktree 的实际创建仍使用 `drift git worktree create`；`TaskCreate` 不隐式执行 Git 写操作。
- 切换不会删除旧 worktree，也不会自动合并或切回旧根目录。
- 不实现并行 Agent、自动合并和冲突解决。

## 验收

```text
go test ./internal/tool -run TestTaskSwitchSelectsExistingWorktree -count=1
go test ./... -count=1
go vet ./...
go build ./cmd/drift
git diff --check
```

通过条件：无 worktree 的任务切换被拒绝；已存在且路径受控的任务可以切换；切换后的 Agent 工具使用新根目录；越界路径仍被拒绝。

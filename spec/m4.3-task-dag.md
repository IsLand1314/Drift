# M4.3：任务依赖和状态同步

## 目标

为任务建立受控依赖 DAG，统一任务状态，并在会话恢复时安全重建可运行状态。

## 实现

- `TaskState.DependsOn` 保存任务 ID 依赖；创建和更新时拒绝未知依赖、重复依赖和循环依赖。
- 新状态集合为 `pending / blocked / running / completed / failed / cancelled`，保留 `timeout` 终态；旧会话的 `in_progress` 读取后归一化为 `running`。
- `TaskRun` 在依赖未全部 `completed` 时将任务置为 `blocked`，不调用子 Agent；依赖完成后允许进入 `running`。
- 会话恢复把崩溃前的 `running` 任务安全回收到 `pending`，并按依赖重新计算 `blocked/pending`；不会伪造已完成结果。
- `TaskStatus`、任务持久化和审计沿用 task ID，结果不会跨任务混合。

## 非目标

- 不自动重试失败任务，不自动执行被阻塞任务。
- 不实现跨会话远程调度、消息总线或自动合并；这些属于 M4.4/M4.5。

## 验收

必须证明依赖阻塞、完成后启动、循环拒绝、状态转换和重启恢复；真实 LLM 工具调用仍需在 DeepSeek 工具协议兼容后单独验收。

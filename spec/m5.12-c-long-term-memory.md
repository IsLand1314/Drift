# M5.12-C：跨会话长期记忆

## 目标

让新 Session 可以按关键词检索当前 workspace 中已经批准的事实、决策和经验，但不把完整历史自动注入 Context。

## 已交付

- `.drift/memory/facts.jsonl`、`decisions.jsonl`、`experiences.jsonl` 和 `index.json`；
- 原子更新 index，目录 0700、文件 0600；
- 关键词/来源/状态匹配，结果按更新时间排序且有上限；
- `MemorySearch` 只读工具按 ToolSearch 延迟加载；
- MemorySearch 结果标记为不可信上下文，不授予权限或执行能力；
- 删除只影响当前 workspace 的对应条目；
- 敏感信息、绝对路径、超长条目拒绝写入。

## 非目标

- 不使用向量数据库；
- 不跨 workspace 共享；
- 不自动把全部长期记忆灌入每次请求；
- 不允许模型直接修改权限、沙箱或认证配置。

# M5.4：工具 Schema 加载策略

## 策略

- `dispatch`：默认策略。初始只暴露 ToolSearch 和必要控制工具，搜索并明确加载后，下一轮才暴露完整 schema。
- `eager`：启动时暴露当前注册表全部工具；适合工具数量少、上下文充足的场景。
- `native`：预留给 Provider 原生 deferred tool reference。当前 provider-neutral `llm.Request` 尚未定义该协议，因此安全降级为 `dispatch`，不会假装已启用原生能力。

配置或命令行：

```toml
tool_loading = "dispatch"
```

```text
drift chat --tool-loading eager
drift chat --tool-loading dispatch
drift chat --tool-loading native
```

MCP 工具遵循同一策略；eager 模式在 MCP 连接晚于注册表创建时仍会自动加载新发现的工具。

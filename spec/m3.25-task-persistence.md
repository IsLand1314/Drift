# M3.25：任务状态持久化与会话恢复

M3.25 将 M3.24 的会话内任务状态纳入现有 conversation snapshot。任务仍属于单个会话，不引入依赖、并行 Agent 或跨 workspace 共享。

## 范围

- `TaskCreate`、`TaskUpdate` 产生的任务状态随会话快照保存；
- `/resume` 和会话切换后恢复任务 ID、标题、描述和状态；
- `/new`、清空会话或切换到无任务会话时清除当前注册表任务；
- 快照加载对任务 ID、状态、字段长度和重复 ID 做校验，失败时拒绝恢复；
- 旧快照没有 `tasks` 字段时按空任务列表兼容处理；
- 不实现任务依赖、并行调度、跨会话任务或持久化到独立任务数据库。

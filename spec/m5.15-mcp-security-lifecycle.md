# M5.15：MCP 安全与生命周期

## 已实现范围

- stdio MCP 在 `auto/required` 模式下复用 OS 沙箱；Linux 使用 bwrap，Windows 使用 AppContainer + Job Object，受保护 `.drift`/`.git` 使用 ACL/临时只读遮蔽，默认隔离网络；
- `network_enabled` 只由可信 `.drift/mcp.json` 配置控制，模型不能改变；
- MCP 子进程继承上下文取消并由 `die-with-parent`/Job Object/进程句柄清理；
- `/mcp disconnect <name>`、`/mcp reconnect <name>` 和连接状态审计；
- initialize capability 缓存；
- Resource `file://` URI 必须位于 workspace 内；
- Resource/Prompt 输出标记为不可信，统一大小限制和非文本摘要；
- 资源内容不能改变系统提示、权限模式或沙箱策略。

## 验收

- stdio、HTTP Server 连接与断开测试；
- sandbox required 不可用时 fail-closed；
- 恶意 file URI、超限内容、取消和子进程退出测试；
- `go test ./...`、race、vet、build、diff check 全部通过。

## LLM 验收

- 独立只读评审必须检查 DAG、状态和恢复证据；不得调用写入、命令或任务执行工具。
- 本轮 `deepseek-chat -p` 独立只读评审：`VERDICT: PASS`；确认依赖 DAG、状态机、循环拒绝、恢复重算和持久化均有证据覆盖。
- 本轮真实运行创建 `task-1 -> task-2` 依赖：先运行 `task-2` 得到 `TaskRun failed: blocked by dependencies`；完成 `task-1` 后再次运行 `task-2`，依赖门禁解除并最终 `completed`。另一个显式加载 `ToolSearch → ReadFile` 的子任务也完成并合并。消息列表和汇总均能读取子 Agent 的 progress/result。

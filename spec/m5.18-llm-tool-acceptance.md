# M5.18：真实 LLM 工具链验收

## 验收原则

确定性 Go 测试只能证明运行时契约；真实 Provider 验收单独记录模型是否真的产生原生 tool call、是否按需加载工具，以及失败时是否保持安全边界。

## 链路

`ToolSearch → ReadFile/WriteFile/Bash → MCP tools/call`。写入、命令和 MCP 调用仍经过权限、沙箱、审计链路；模型输出 DSML/XML 等文本不视为工具调用。

## Provider 矩阵

| --- | --- | --- |
| DeepSeek OpenAI Compatible | 原生 `ToolSearch → ReadFile` 通过；WriteFile/Bash/MCP 结果按本轮可用配置记录 | `artifacts/verification/m5.18/acceptance.md` |
| OpenAI Compatible | HTTP 401，未发起工具链，按失败记录 | `artifacts/verification/m5.18/acceptance.md` |

伪工具调用、用户拒绝、超时、有限重试、取消后的恢复分别使用真实输出或确定性回归测试记录；不能把模拟测试写成真实模型通过。

# M5.12-E：Skill 发现、安装与管理

## 已交付

- `skill list` 发现 workspace `.drift/skills/*/SKILL.md`；
- `skill show` 加载经过名称、大小、UTF-8、普通文件校验的 Skill；
- `skill install` 只复制本地 source 下的 `SKILL.md`，不执行、不复制二进制和任意 payload；
- `skill install --preview` 只展示将复制的文件，实际安装仍需用户显式执行 `skill install`；
- `skill remove` 只删除名称合法的 workspace Skill 目录；
- `skill enable` / `skill disable` 用 `.drift/skills/state.json` 管理启用状态；禁用 Skill 不会删除内容；
- 每个新安装 Skill 生成或校验 `skill.json`（名称、三段版本号、描述），`list`/`load` 暴露版本元数据；
- 安装和删除写入 `.drift/audits/skill-lifecycle.jsonl`，不触碰 Session 或 Memory；
- 安装使用临时 staging 目录后原子 rename；
- Skill 内容作为指令上下文，不得改变权限、沙箱或认证配置。

## 非目标

- 不从网络自动下载；
- 不执行 Skill 安装脚本；
- 不跨 workspace 共享 Skill；
- 不让 Skill 自动写入 Memory。

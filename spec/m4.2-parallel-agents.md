# M4.2：多子 Agent 并行

## 目标

允许多个相互独立的任务同时运行，并保持并发上限、Worktree 隔离、单任务失败隔离和按任务取消。

## 实现

- `ChildManager` 通过 `NewChildManager(limit)` 管理活动子 Agent；当前 chat 宿主上限为 `4`。
- `TaskRun` 对不同任务异步启动，不共享任务结果；`TaskStatus` 读取各自状态和结果；`TaskCancel` 只取消指定任务。
- 达到并发上限时新任务安全拒绝，不排队、不静默丢弃。
- 一个子 Agent 进入 `failed` 不会取消其他活动子 Agent；宿主退出时 `Shutdown` 统一取消并等待全部活动子 Agent。
- 每个子 Agent 仍使用自己的任务 Worktree，生命周期事件携带任务 ID。

## 边界

- 本阶段不实现任务依赖 DAG、自动合并或 Agent 间消息。
- 当前并发上限是代码常量，不做运行时配置；需要可配置时再增加配置入口和持久化语义。

## 验收

确定性验收必须证明：两个子 Agent 同时进入运行、第三个超过上限被拒绝、一个失败不影响另一个完成、单独取消不影响其他任务、结果和 Worktree 不交叉。真实 LLM 工具调用仍受 M4.1 的 DeepSeek 伪工具格式阻塞，不能以自动化测试代替该外部条件。

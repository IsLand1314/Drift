# M3.17 Git Revert Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans skill to execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a safe, audited `drift git revert <commit> --yes` command that creates a reverse commit without ever discarding uncommitted work.

**Architecture:** Keep Git rollback separate from Drift change-set restore. Add a small `internal/git` package that performs non-shell Git preflight and execution, while `internal/app` owns argument parsing, permission-mode decisions, audit writer setup, and user-facing output. Use the existing sandbox preview/execution path for the final fixed Git command and the existing JSONL event schema for audit records.

**Tech Stack:** Go standard library (`os/exec`, `context`, `regexp`, `encoding/json`), existing `internal/tool` sandbox, `internal/session` JSONL audit, Go `testing`.

**Spec:** `docs/superpowers/specs/2026-10-03-m317-git-revert-design.md`

## Global Constraints

- Never invoke `git reset --hard`, `git clean`, forced checkout, rebase, merge, remote push, or automatic `git revert --abort`.
- Reject any dirty, untracked, conflicted, non-Git, or non-commit target before starting `git revert`.
- Resolve a commit to one full SHA and reject merge commits in M3.17.
- Never concatenate unvalidated user input into a shell command.
- `--yes` is explicit CLI confirmation; chat-triggered execution still uses permission mode, approval, and required sandbox.
- Do not write Git rollback operations into a Drift change set.
- Audit records must omit full command output, file content, credentials, and absolute paths.

- [ ] **Step 3: Implement non-shell preflight**

Use `exec.CommandContext(ctx, "git", "-C", root, ...)` with separate argument slices:

```go
func gitOutput(ctx context.Context, root string, args ...string) ([]byte, error) {
	cmd := exec.CommandContext(ctx, "git", append([]string{"-C", root}, args...)...)
	return cmd.Output()
}
```

Resolve the repository root with `rev-parse --show-toplevel`, require an empty `status --porcelain`, resolve `target^{commit}`, reject `rev-parse --verify <sha>^2` success (merge commit), and obtain preview text from `git show --stat --oneline --no-renames <sha>`.

# M2.0 Workspace Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add explicit, workspace-local Codex-style Skills without changing Drift's read-only tools, Agent budgets, Provider contract, or audit privacy rules.

**Architecture:** Add a small `internal/skill` loader that validates `.drift/skills/<name>/SKILL.md`, then let `internal/app` inject one selected Skill as provider-neutral system context into `agent.Runner`. Add `skill list/show` as local commands that execute before Provider creation; normal runs use `-skill <name>` and keep all existing Agent and TTY paths.

**Tech Stack:** Go 1.26+, standard library (`os`, `filepath`, `unicode/utf8`, `regexp`, `encoding/json`), existing `llm.Client`, `agent.Event`, JSONL session writer, and `testing`/`httptest`. No new runtime dependency.

**Spec:** `docs/superpowers/specs/2026-10-01-m20-skills-design.md`

## Global Constraints

- Skills are discovered only under the current workspace `.drift/skills/` directory.
- A Skill entry file is exactly `.drift/skills/<name>/SKILL.md`; names use ASCII lowercase letters, digits, and hyphens, length 1–64.
- Do not follow symlinks, accept absolute paths, accept `..`, read outside workspace, or load user/global directories.
- One run loads at most one Skill; `SKILL.md` is UTF-8 and at most 64 KiB.
- Skill content is extra system context, never part of the user prompt, tool schema, or Provider-specific branch.
- Skills cannot add tools, expand workspace boundaries, read `.env`, execute commands, write files, use network URLs, or run scripts.
- `skill list/show` run before Provider creation and do not require an API key.
- Skill selection is explicit; no automatic matching, inheritance, nested references, front matter, or remote download.
- Full conversation snapshots do not persist Skill text; a resumed process must select the Skill again.
- Session audit may record only the selected Skill name or a stable load-failure stage; never record Skill text.
- Preserve `go test ./...`, `go vet ./...`, `go build ./cmd/drift`, `git diff --check`, OpenAI/Anthropic behavior, and M1.10 `Done - <seconds>s` output.

### Task 1: Add the workspace Skill loader

**Files:**
- Create: `internal/skill/skill.go`
- Create: `internal/skill/skill_test.go`

**Interfaces:**
- `type Info struct { Name string; Path string; Size int64 }`
- `type Skill struct { Info; Content string }`
- `func List(root string) ([]Info, error)` discovers immediate child directories under `root/.drift/skills` and only reports directories containing a regular `SKILL.md`.
- `func Load(root, name string) (Skill, error)` validates the name and loads one bounded UTF-8 entry file.
- `func ValidateName(name string) bool` is shared by CLI validation and loader tests.

- [ ] **Step 1: Write failing validation and discovery tests**

Create temporary workspace fixtures for valid names, uppercase/underscore names, empty names, nested names, missing `SKILL.md`, directories in place of `SKILL.md`, symlinked Skill directories, and a valid `project-overview/SKILL.md`. Assert `List` returns only the valid Skill and `Load` returns its exact UTF-8 content.

- [ ] **Step 2: Run the loader tests and verify they fail**

Run `go test ./internal/skill -count=1 -v`. Expected: FAIL because the package and exported functions do not exist yet.

- [ ] **Step 3: Implement bounded discovery and safe loading**

Use one ASCII name regexp `^[a-z0-9][a-z0-9-]{0,63}$`. Read only immediate children of `.drift/skills`; reject symlink entries and require `SKILL.md` to be a regular non-symlink file. Resolve the candidate under the workspace root, read at most `64<<10+1` bytes, reject files over 64 KiB, and validate `utf8.Valid(data)`. Sort `List` by name and return errors containing only stable reasons, not absolute paths or file contents.

- [ ] **Step 4: Add boundary tests and commit**

Test 64 KiB success, 64 KiB+1 rejection, invalid UTF-8, absolute/`..` names, and an outside-pointing symlink. Assert errors do not contain fixture roots or contents. Run `go test ./internal/skill -count=1 -v`, then commit:

```powershell

git commit -m "功能：增加 Workspace Skill 加载器"
```

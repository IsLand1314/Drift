# M4.3 任务 DAG 与状态同步计划

## 目标

让任务依赖可持久化、可校验、可恢复，并阻止依赖未完成的任务启动。

## 最小实现

1. 在任务状态中保存 `depends_on`，创建/更新时做引用和环检测。
2. 统一新状态为 `pending/blocked/running/completed/failed/cancelled`。
3. `TaskRun` 检查依赖并维护 `blocked → pending → running` 的安全转换。
4. 恢复会话时把活动任务回收到 `pending`，再按依赖重算阻塞状态。
5. 用 TDD 覆盖依赖阻塞、循环、状态和恢复，不引入外部调度服务。

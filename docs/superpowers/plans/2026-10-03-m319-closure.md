# M3.19 Safety and Interaction Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Close the remaining interaction and safety regressions around Windows Bash guidance, chat-turn recovery, sandbox outcome reporting, permissions, audit records, and Git revert without adding a new security backend.

**Architecture:** Reuse the existing `agent.Runner`, chat loop, tool sandbox selector, permission resolver, audit event model, and Git revert preflight. Keep model-facing tool names and the `off/auto/required` sandbox contract unchanged. Each change is guarded by a focused regression test before implementation.

**Tech Stack:** Go, standard library, Bubble Tea chat UI, existing JSONL session/audit store, Linux `bwrap`, Windows AppContainer.

**Spec:** `spec/current.md`, sections “M3.19：安全层与交互收口” and existing M3.16–M3.18 acceptance criteria.

## Global Constraints

- Do not add a new sandbox backend, Git-specific sandbox, MCP integration, ToolSearch, vector database, or multi-Agent code.
- Preserve `default/acceptEdits/plan/bypassPermissions` and `off/auto/required` semantics.
- `required` must fail closed; `auto` may fall back only with `sandboxed=false` recorded.
- User input and audit metadata must not be silently lost on a failed Agent turn.
- Preserve workspace, `.drift`, `.git`, timeout, process-tree, and approval boundaries.
- Do not modify the user-owned pending documents under `doc/Process/`.
